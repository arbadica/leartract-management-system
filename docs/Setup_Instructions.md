# LearnTrack Environment Setup Instructions

## JDK Details
- **JDK Version**: OpenJDK 17 or higher
- **Tools**: Terminal / Command Line Interface, IDE (IntelliJ / Eclipse / VS Code)

## Compilation & Run Instructions via CLI

1. Open terminal at the project root directory.
2. Compile all source files into a `bin` output directory:
   ```bash
   javac -d bin src/com/airtribe/learntrack/**/*.java
